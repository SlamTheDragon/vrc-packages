# Implementation Plan: Sector 4 (Root Distribution Pipeline and Monorepo Management)

## Canonical Architectural Covenants

1. **Owned Paths (Strictly Distinct from Product Sectors)**: Root `package.json`, `scripts/`, `.github/workflows/`, `config.versions.json`, `config.preview.versions.json`, and `tests/`.
2. **Truth Cascade**: Follow [`AGENTS.md`](../../AGENTS.md) -> [`VISION.md`](../research/decisions/VISION.md) (`T00`, `T02`, `T05`, `T07`) -> [`SYSTEM_MAP.md`](../source/SYSTEM_MAP.md) -> [`PUBLISHING.md`](../source/PUBLISHING.md) and [`AGENT_PUBLISHING_PROCEDURE.md`](../research/decisions/AGENT_PUBLISHING_PROCEDURE.md).
3. **Pipeline Isolation and Root Test Rule**: Keep root distribution tooling strictly separate from product feature work. Run root tests (`bun test ./tests`) ONLY when root tooling (`scripts/`, `tests/`, `package.json`, root configs) changes. Any edit to `scripts/`, `.github/workflows/`, or `config*.versions.json` triggers the Rule 06 `edit-guard`.
4. **Sector Ledger Layout and Tracker-Only Main Advancement (`PIPELINE-SCRATCH-RETIRE`)**: Legacy `docs/scratch/` has been deleted after migrating all active tasks into the five 3-file `docs/scratch-<sector>/` ledgers (`IMPLEMENTATION_PLAN.md`, `task_tracker.md`, `handoff.md`). `scripts/delivery.mjs` enforces an explicit 5-path allowlist (`docs/scratch-<sector>/task_tracker.md`) for tracker-only `main` advancement, and `tests/preprod_layout.test.ts` enforces absence of `docs/scratch/` and the exact 3-file footprint per sector.
5. **Publishing Safety, Changelog Stewardship, and Three-File Footprint**: Never hand-edit version configs or root `CHANGELOG.md`. Preserve protected-main reviews, immutable tags, predecessor proof, and owner-only environment approvals. Keep strictly three files here (`IMPLEMENTATION_PLAN.md`, `task_tracker.md`, `handoff.md`). Only Sector 4 Pipeline agents sweep all sector `handoff.md` Publication Requests, maintain [`docs/source/CHANGELOG.md`](../source/CHANGELOG.md), and clear transferred `verified` rows across sector ledgers.
