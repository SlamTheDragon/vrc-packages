Keep `docs/applications/` untouched and stage proposed wiki updates in [`docs/source/reliability/proposed_wiki_changes.md`](../source/reliability/proposed_wiki_changes.md).
5. **Three-File Scratch Footprint and Pipeline-Only Clearing**: Keep strictly three files here (`IMPLEMENTATION_PLAN.md`, `task_tracker.md`, `handoff.md`). Record Tier 3B / 5 outbound handoffs and written Publication Requests strictly in [`handoff.md`](handoff.md). Do not edit `docs/source/CHANGELOG.md` or clear `verified` rows directly (only Sector 4 Pipeline agents transfer notes to `docs/source/CHANGELOG.md` and clear verified rows).
