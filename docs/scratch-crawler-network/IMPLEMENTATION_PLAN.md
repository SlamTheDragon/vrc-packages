# Implementation Plan: Sector 1 (Crawler Network)

## Canonical Architectural Covenants

1. **Owned Paths**: `src-worker/` (Cloudflare Worker + D1 coordinator), `src-worker/packages/network/` (`vrc-packages-network` internal wire/policy package), and `src-crawler/` (headless Bun-compiled node binary `vrcp-crawler-node`).
2. **Truth Cascade**: Follow [`AGENTS.md`](../../AGENTS.md) -> [`VISION.md`](../research/decisions/VISION.md) (`T00` to `T05`) -> [`SYSTEM_MAP.md`](../source/SYSTEM_MAP.md) -> [`LEGAL.md`](../../LEGAL.md) -> [`src-worker/AGENTS.md`](../../src-worker/AGENTS.md) and [`src-crawler/AGENTS.md`](../../src-crawler/AGENTS.md).
3. **Process and Dependency Isolation**: Coordinator and Crawler Node run as separate processes communicating strictly through versioned HTTP payloads. Zero sibling source imports or `file:../src-*` links; consume `vrc-packages-api` (preview) and `vrc-packages-network` (GitHub Release tarball) strictly as declared dependencies.
4. **Leased Ingestion, Robots, and Safety**: Nodes fetch only under unexpired 120s coordinator leases and fail closed on coordinator loss. Enforce active scoped source-access profiles, node-delegated RFC 9309 `robots.txt` preflight, SHA-256 capability tokens, strict `publishClasses` filtering, and zero binary downloads.
5. **Three-File Scratch Footprint and Pipeline-Only Clearing**: Keep strictly three files here (`IMPLEMENTATION_PLAN.md`, `task_tracker.md`, `handoff.md`). Historical owner dispositions live in [`owner_dispositions.md`](../research/decisions/owner_dispositions.md). Record Tier 2 / 3A / 4A outbound handoffs and written Publication Requests strictly in [`handoff.md`](handoff.md). Do not edit `docs/source/CHANGELOG.md` or clear `verified` rows directly (only Sector 4 Pipeline agents transfer notes to `docs/source/CHANGELOG.md` and clear verified rows).
